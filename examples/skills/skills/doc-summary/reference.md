# doc-summary — Format Reference

## Full template

```markdown
# [Document Title]

## Summary
[1–2 sentences: the document's main point or conclusion]

## Key Points
- [Most important point]
- [Second point]
- [Third point]
- (3–5 bullets total)

## Notable Details
- [Dates, numbers, names, or data worth preserving]

## Action Items *(include only if the document implies tasks)*
- [ ] [Task]
```

## Adapting by content type

| Content type     | Suggested section names                        |
|------------------|------------------------------------------------|
| Meeting notes    | Decisions, Action Items                        |
| Technical spec   | Requirements, Constraints, Open Questions      |
| Research article | Findings, Methodology, Limitations            |
| News / article   | Context, Key Facts, Implications              |
